ANDROID (Android Studio)
----------------------------
Le dossier "android" est maintenant un projet Gradle complet et valide.
Ouvrez directement le sous-dossier "android" dans Android Studio (File →
Open → sélectionnez le dossier "android" de ce projet). PAS besoin de
relancer "npx cap add android" — c'est déjà fait. Une fois la synchronisation
Gradle terminée : Build → Build App Bundle(s) / APK(s) → Build APK(s).

iOS (Xcode, sur Mac)
------------------------
Le dossier "ios" est maintenant un projet Xcode complet. Ouvrez directement
"ios/App/App.xcodeproj" dans Xcode. Ce projet utilise Swift Package Manager
(pas CocoaPods) pour ses dépendances — Xcode les télécharge tout seul à
l'ouverture, pas besoin d'installer CocoaPods ni de lancer "pod install".

GITHUB (construction automatique de l'APK dans le cloud)
--------------------------------------------------------------
Le fichier .github/workflows/build-android.yml est déjà inclus et bien
placé dans ce zip. Publiez ce dossier complet (avec le dossier caché
".github" — pensez à activer l'affichage des fichiers cachés dans
l'Explorateur/Finder pour vérifier qu'il est bien présent avant d'envoyer)
dans votre dépôt GitHub. L'onglet "Actions" devrait alors lancer la
construction automatiquement.
